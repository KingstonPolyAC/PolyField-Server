## Installation

### macOS

1. Download and unzip `polyfield-control-server-Mac-Universal.zip`
2. Move the app to your Applications folder
3. Right-click the app and select **Open**
4. Click **Open** in the dialog that appears

> The app is not notarised with Apple, so this step is required on first launch.

### Windows

1. Download and unzip `polyfield-control-server-Windows.zip`
2. Run `polyfield-control-server.exe`
3. If Windows SmartScreen appears, click **More info** then **Run anyway**

## Features

- Field event management for throws, horizontal jumps, and vertical jumps
- Integration with OpenTrack, Roster Athletics, and Athletics App
- Live display boards and standings tables
- Wind gauge support via UDP
- Heatmap visualisation and social media export
- Real-time result synchronisation with PolyField App
